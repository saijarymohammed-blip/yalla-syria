# يلا سوريا — نظام إدارة الفريق التطوعي

تطبيق ويب عربي (RTL) للجوال لإدارة حضور المتطوعين، بتسجيل دخول وقاعدة بيانات مركزية (Supabase).

## المميزات
- **مدير**: لوحة تحكم، الحاضرون/الغائبون/الإجازات، نسبة الحضور، ساعات اليوم، الحضور حسب القسم، خريطة المواقع، التقرير اليومي (طباعة)، حاسبة الساعات (CSV)، تعديل الحركات، التعاميم، إدارة المتطوعين والأقسام والإعدادات.
- **متطوع**: يسجّل دخوله بحسابه ويضغط "تسجيل حضور / انصراف" (مع GPS)، ويقرأ التعاميم فقط.
- صلاحيات مفروضة من قاعدة البيانات (RLS): المتطوع لا يرى بيانات غيره ولا يستطيع التعديل على أي شيء عدا تسجيل حركاته.

## الإعداد (حوالي 10 دقائق)

### 1) إنشاء قاعدة البيانات
1. أنشئ حساباً مجانياً على https://supabase.com ثم **New project**.
2. من القائمة: **SQL Editor → New query**، الصق محتوى `schema.sql` كاملاً واضغط **Run**.
3. (موصى به) **Authentication → Providers → Email**: عطّل **Confirm email** ليدخل المتطوعون مباشرة بعد التسجيل.

### 2) ربط التطبيق
من **Project Settings → API** انسخ `Project URL` و `anon public key` والصقهما في `config.js`.

### 3) التشغيل والنشر
تجربة محلية:

    cd yalla-syria
    python3 -m http.server 8080      # ثم افتح http://localhost:8080

للنشر: ارفع المجلد كما هو على **Netlify** (سحب وإفلات) أو **GitHub Pages** أو **Vercel**. HTTPS مطلوب لعمل GPS.
بعد النشر: **Authentication → URL Configuration** أضف رابط موقعك في Site URL.

### 3.5) تثبيت التطبيق على شاشة الجوال (PWA)
بعد النشر على رابط HTTPS:
- **أندرويد (Chrome)**: افتح الرابط ← يظهر شريط "ثبّت التطبيق" ← اضغط تثبيت (أو القائمة ⋮ ← تثبيت التطبيق).
- **آيفون (Safari)**: افتح الرابط ← زر المشاركة ⎙ ← "إضافة إلى الشاشة الرئيسية".
يفتح بعدها بأيقونة "يلا سوريا" وبملء الشاشة كأي تطبيق، وتصله التحديثات تلقائياً عند كل نشر جديد (غيّر VERSION في sw.js عند التحديث).

### 4) أول استخدام
- **أول حساب تنشئه يصبح مديراً تلقائياً** — أنشئه أنت أولاً.
- أرسل رابط التطبيق للمتطوعين؛ كل واحد ينشئ حسابه ويظهر عندك تلقائياً في قائمة المتطوعين (عيّن قسمه من "تعديل").
- من **الإعدادات** اضغط "استخدام موقعي الحالي" وأنت في مقر العمل، وحدّد نصف القطر والأقسام.
- لترقية شخص إلى مدير: نفّذ في SQL Editor السطر الأخير المعلّق في `schema.sql`.

## الوضع المحلي (بدون Supabase)
إن تركت `config.js` فارغاً يعمل التطبيق بدون خادم، والبيانات تُحفظ داخل متصفح هذا الجهاز فقط.
عند أول فتح تظهر شاشة "إنشاء حساب المدير" (اسم + كلمة مرور)، وبعدها شاشة دخول بكلمة المرور.
تنبيه: هذه حماية بسيطة على مستوى الجهاز فقط. للاستخدام الفعلي مع الفريق اربط Supabase.
لا توجد أي بيانات وهمية؛ يبدأ التطبيق فارغاً وتضيف المتطوعين من "المتطوعون".

## هيكل المشروع
    index.html           الصفحة الرئيسية
    css/style.css        التصميم
    config.js         مفاتيح Supabase
    js/store.js          طبقة البيانات (محلي / سحابي)
    js/app.js            الواجهة والصفحات وتسجيل الدخول
    schema.sql  الجداول والصلاحيات

## ملاحظات
- يُحمَّل آخر 120 يوماً من الحركات؛ لوحة المدير تتحدث تلقائياً كل دقيقة.
- مفتاح anon آمن للنشر العلني لأن الحماية في قواعد RLS. لا تضع مفتاح service_role في التطبيق أبداً.
